# ADR-0005：跨资源一致备份与隔离恢复

记录日期：2026-09-21。

状态：提议，待实施与恢复演练验证。来源：文档审查指出数据库、媒体、主题及外部投递缺少统一恢复边界；本次按修订请求补充建议，不回填为既有产品决定。

背景：数据库事务不能覆盖对象存储和第三方服务。独立导出数据库、复制媒体或恢复 outbox，可能产生缺失附件、无法解密的配置和重复外部投递。

建议首期采用维护窗口：停止所有写入与相关 worker，在静止状态下建立数据库、媒体、主题及秘密恢复材料的关联清单，验证后才标记备份完成。恢复先隔离，撤销旧会话和待用凭据，重建派生缓存/索引；外部投递经核对后再开放。

替代方案：在线数据库快照配合对象版本、增量日志或持续恢复。它们可减少停机和数据丢失窗口，但需要更复杂的跨资源切点、对象保留和重放协议；首期不默认承担这部分复杂度。单独逻辑导出不能替代完整部署备份。

代价：备份期间暂停服务写入，首期可采用完整维护停机；需要备份容量、独立密钥保管和定期演练。RPO/RTO、频率及保留期在部署规格中确定，当前不作数值承诺。外部副作用不能由恢复数据库自动撤销，也不承诺恰好一次重放。

验收与操作步骤见 [备份与恢复](../operations-and-recovery.md)。未来改成在线方案时另记替代决策，并证明媒体引用、秘密材料和外部任务具有等价恢复语义。
