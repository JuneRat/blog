# ADR-0004：公开内容 generation

状态：提议，需验证。来源：模板数据函数带来动态列表依赖后的工程建议，并非用户指定实现。

建议早期缓存采用站点级公开内容 generation，业务公开结果变化时在数据库事务中原子递增。页面按 generation、主题、设置和模板 API 版本寻址。

替代方案包括：暂不启用页面缓存、按集合版本/依赖标签失效、记录运行时查询依赖。站点级版本实现简单，但任意公开变更可能让全站缓存变冷，并使写事务竞争同一版本记录。

边界：generation 不是领域聚合，不单独保证立即撤回。读端版本新鲜度、正文查询隔离、并发请求的可见性时点和 CDN 策略必须与它一起定义。正文输出前后检查只能缩小竞态范围，不能撤销已发送字节。

早期内容闭环可不启用页面缓存。启用前验证发布期间的命中率、整体延迟、重建并发与撤回语义，再决定保留全站版本还是细化。详见 [主题与渲染](../themes-and-rendering.md)。
