# ADR 模板

新增决策时复制下面的骨架，使用下一个空闲编号和简短文件名。只填写已有证据：记录日期是原决策记录日期，无法确认的历史日期写“原记录未注明”；不要把文档整理日期当作原决策日期。

```markdown
# ADR-NNNN：决策标题

- 状态：提议
- 记录日期：YYYY-MM-DD
- 关联决策：无；有关联时填写链接及更新范围
- 当前参考：填写现行架构、功能说明或开发指南的链接

## 背景

说明遇到的具体问题、适用范围和已有约束。

## 决策

说明选择及理由。提议阶段使用待验证措辞，已采纳时记录实际选择。

## 考虑过的方案

列出实际比较过的方案及取舍；没有相关记录时省略本节，不补写虚构的讨论。

## 后果与限制

说明收益、代价、保留的限制和必要的验证边界。

## 后续变更

发生后续决策时，记录关联链接及被更新的具体范围；尚无变化时可省略。
```

决策状态使用“提议”“已采纳”“部分被替代”“已被替代”。实现进度和上线验收放[路线图](../product-roadmap.md)；被替代时同时更新旧记录页首、后续变更和[索引](README.md)。

当前配置、API、开发步骤和可变参数由专项文档维护，ADR 链接其权威入口。历史决定保留原意；既有编号和文件名保持稳定，后续改变独立选择时新增记录并标明替代范围。
