# ADR-0003：产品与外部接入基线

- 状态：已采纳
- 记录日期：原记录未注明
- 关联决策：[ADR-0008：核心存储与交付分期](0008-thirteen-table-blog-core.md)
- 当前参考：[功能路线](../product-roadmap.md)、[身份与后台](../identity-and-admin.md)、[扩展设计候选](../extensions-and-data.md)

## 背景

项目需要明确协作方式、发布流程、身份接入、前后台形态和扩展边界，以约束后续存储与技术设计。

## 决策

以下是产品方向，不是功能实现清单。

| 选择 | 取舍 |
|---|---|
| 单站点多人协作、内置与自定义角色、管理员邀请 | 不承担多租户与公开注册的首期复杂度 |
| 作者可直接发布自己的文章 | 无强制审核，仍需 own/any 授权 |
| 通用 OIDC + GitHub | 身份提供商和本地权限分开，绑定和恢复另行设计 |
| React + TypeScript + Vite 后台，公开博客 SSR | 后台开发独立，增加 API 契约与前端构建成本 |
| 首期仅 PostgreSQL，保留多数据库适配 | 不为未实现驱动创建支持承诺 |
| 主题、Webhook、外部服务等受限扩展 | 不提供可上传的 Rust/WASM/JS 运行时 |
| 外部搜索与统计接入能力 | 提供商另行选择，正常阅读不依赖其可用性 |

## 后果与限制

方向的采纳不代表邀请、自定义角色编辑、外部集成或其他数据库已交付，也不使新增功能建议自动成为既定需求。具体能力仍需明确范围、存储、权限及失败恢复规则。
