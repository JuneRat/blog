# ADR-0003：产品与外部接入基线

状态：产品方向已采纳，待实施。来源：用户在本会话中的明确需求和逐项选择。当前具体存储与交付范围由后续 [ADR-0008](0008-thirteen-table-blog-core.md) 更新：13 表核心先采用 CLI 账号开通，管理员邀请延期；本文保留最初的产品选择记录。

| 选择 | 取舍 |
|---|---|
| 单站点多人协作、内置与自定义角色、管理员邀请 | 不承担多租户与公开注册的首期复杂度 |
| 作者可直接发布自己的文章 | 无强制审核，仍需 own/any 授权 |
| 通用 OIDC + GitHub | 身份提供商和本地权限分开，绑定和恢复另行设计 |
| React + TypeScript + Vite 后台，公开博客 SSR | 后台开发独立，增加 API 契约与前端构建成本 |
| 首期仅 PostgreSQL，保留多数据库适配 | 不为未实现驱动创建支持承诺 |
| 主题、Webhook、外部服务等受限扩展 | 不提供可上传的 Rust/WASM/JS 运行时 |
| 外部搜索与统计接入能力 | 提供商仍待选择，正常阅读不依赖其可用性 |

这些决定不需要再次确认。新增功能建议不因此自动成为已确认需求。见 [功能路线](../product-roadmap.md)、[身份与后台](../identity-and-admin.md)、[扩展与数据](../extensions-and-data.md)。
