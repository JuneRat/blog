# 2026-10-03 高、中优先级功能本地隔离验收

本次按本地隔离范围验证：服务监听回环地址，PostgreSQL 使用已有的本机 `blog-postgres` 测试容器，验收创建两个随机数据库和独立媒体、主题、配置与备份目录。SMTP 由临时回环收件器接收，不连接外部邮件服务。

## 构建与证据

验收时 HEAD 为 `dccbd7bed88522957d35909ee54d481b31b0a789`，包含撤权与业务提交一致性修复；文档状态修正单独提交为 `0dc2f74`。此前五项功能分别为 Markdown 发布效果一致性、SMTP 邀请与找回、公开搜索与作者归档、主题升级回滚预览、服务端修改草稿与修订历史。

[原始 JSON 报告](priority-features-local-2026-10-03.json)记录 16 个阶段全部通过，总耗时 177.858 秒；[执行日志](priority-features-local-2026-10-03.log)保留 12 个真实 Edge 浏览器场景的通过结果。

报告中的 `tracked_changes=true` 包含当时尚未提交的验收脚本和原有 12 处前端改动。前端改动已按补丁逐行对照初始状态，均保持不变；它们进入本机 SPA 构建，但不包含在本轮提交中。服务端使用 debug 构建，后台使用 Vite 生产构建，不将本报告当作干净发布镜像的验证。

为避免其他 Cargo 命令重新链接服务端影响重启过程，最终运行先复制服务端到独立临时目录，通过 `--binary` 固定该副本，并在运行前后校验其 SHA-256 与报告一致。所验服务端 SHA-256 为 `27ae0006a13f154f81ae24426337162deaa30ae4564870a7bcd62ee52efa5faf`；后台入口、验收主脚本、业务场景和 SMTP 收件脚本的指纹见 JSON。验收结束后固定副本也已清理。
