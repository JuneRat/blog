# 功能范围与实施路线

本文是功能交付状态与后续验收的唯一清单。更新日期：2026-10-01。专项文档分别说明当前契约和已采纳目标设计，ADR 保留决策过程；不在多处维护里程碑进度。

“已实现”表示仓库已有实现和对应验证，不表示已经通过生产部署验收。“待验收”与“未实现”分开记录；候选方案不因写入文档而成为本版承诺。

## 1. 已确认范围

- Rust 模块化单体：四层加 server 装配入口，共五个 crate。
- 单站点多人协作，公开 MiniJinja SSR，后台 React + TypeScript + Vite SPA；作者可直接发布自己的文章，无强制审核。
- PostgreSQL 为当前唯一数据库。新的 [19 表基线](database-design.md)已确认，包含 18 张业务表与 sessions；固定后台任务追加运行/计划两表，当前为 21 张应用表。身份会话、媒体、内容、目录和评论已适配，保留期、新库恢复、正式媒体显式清理和已有业务写入口的事务审计已接入。
- 目标为 Post 单分类、多系列、多标签；分类可有父节点，系列采用可重复排序权重。Page 无作者，作为全站资源，具有独立回收站。
- RBAC、内置与自定义角色的方向保留；首批外部身份为通用 OIDC 与 GitHub。本地密码与持久会话按后续决策纳入。
- 扩展采用主题、Webhook 和外部服务等受限入口；多数据库、搜索、统计及其他扩展按使用场景分别立项，不提供通用可执行插件安装器。

### M5 上线门槛

每次候选版本使用[上线验收记录模板](release-acceptance-template.md)建立独立记录，先填写目标环境、数据规模、负责人和可量化阈值，再执行并链接证据。阈值必须由部署方按用途确定；示例负载和本地结果不是生产承诺。未填写阈值、没有对应环境证据或存在未解决失败时，保持下列项目未勾选。

上线验收清单：

- [ ] 确定部署规模、容量、备份频率/保留期及 RPO/RTO；记录应用构建、迁移版本与配置。
- [ ] 在拟上线环境通过真实浏览器验证登录、权限与撤权、本地草稿恢复、预览、多人编辑冲突、发布/撤回/预约、Post/Page 回收站及永久删除完整流程；记录浏览器版本及失败截图/trace。
- [ ] 验证正文图片、封面、头像和 logo 的上传、授权、公开访问与回收；完成含媒体文件的空环境恢复，核验数据库引用与文件一致。
- [ ] 验证部署层能够停止全部写入；完成故障中断、秘密缺失、损坏备份、会话清空与重新开放演练，记录实际恢复点和耗时。
- [ ] 按目标数据规模完成持续混合读写压测，分别核对读写 P95/P99、错误率、冲突、内存和池占用；验证渲染过载、数据库故障后恢复及迁移/HTML 重建耗时，不用原型吞吐代替部署指标。
- [ ] 核验默认及可切换主题的移动端、键盘导航、深浅色、代码展示和阅读排版；验证实际域名下的 canonical、feed、sitemap 与静态资源。

具体恢复操作见[备份与恢复](operations-and-recovery.md)，容量工具见[容量验证](public-read-capacity.md)；勾选本清单需要对应环境的结果，代码测试通过本身不足以勾选生产项。

| 其他设置分组、主题 API 扩展 | 除已采纳的 comments/audit 外，按实际设置/模板需求明确字段权限与 API 契约 |
| 修订与编辑副本、旧路径跳转 | 线上隔离、历史恢复与资源保留；路径冲突、撤回及删除后的地址策略 |
| 文章发布审核工作流 | 是否需要强制审核、角色权限与状态转换；已采纳的定时发布和持久审计见上节 |
| Webhook、搜索、统计、邮件/订阅 | 提供商与使用场景；outbox、重试、授权过滤、隐私及恢复后的外部副作用 |
| MFA/Passkey、自助邮箱找回 | 凭据、限流、会话撤销、账号恢复与通知投递 |
| 完整多实例支持 | OAuth 一次性状态与限流的共享/协调仍未交付；固定后台任务租约不代表整站已支持多实例，不能仅凭共享会话上线多实例 |
| 多语言、第二数据库、代码插件 | 各自业务身份、路径、隔离、迁移和恢复契约；技术边界见[扩展设计候选](extensions-and-data.md) |
| 跨请求公开缓存 | 有实际测量证明必要，先验证新鲜度、失效与撤回语义；[ADR-0004](adr/0004-public-cache-generation.md) 仍是提议 |
